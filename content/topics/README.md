# Topic inventory

This folder is the canonical inventory of approved article topics for this project.

Add approved topic batches here as separate numbered files, for example:

- `TOPICS-001-100.md`
- `TOPICS-101-200.md`

Keep ranges non-overlapping and review all topic files before adding new topics to reduce duplication and search-intent cannibalization.

Article body files, when they are created later, should live separately from this topic inventory.
